# Warmup JavaScript

Nom : El Barjiji Souad

## Description

Ce dépôt contient une série de 10 exercices JavaScript réalisés dans le cadre de la formation Développeur MERN.

Les exercices permettent de pratiquer progressivement les bases de JavaScript jusqu'à des notions intermédiaires.

## Exercices

- Exercice 01 : Ma fiche de profil
- Exercice 02 : Le convertisseur de température
- Exercice 03 : Le compte à rebours de lancement
- Exercice 04 : La liste de courses
- Exercice 05 : La fiche produit
- Exercice 06 : Le panier d'achat
- Exercice 07 : Le générateur de slug
- Exercice 08 : La validation du formulaire d'inscription
- Exercice 09 : La remise fidélité
- Exercice 10 : Le tableau de bord des ventes
